# Attendance Template Upload

Owner CSV workflow for daily attendance.

## Workflow

1. Download the CSV from Schedule > Attendance Upload.
2. Fill one row per employee per work date.
3. Upload the completed CSV.
4. Preview approval, review, skipped, and error counts.
5. Import the file.

Normal schedule matches are approved automatically. General Manager review is
required only for a major schedule variance, absence on a scheduled day, or
attendance on a rest day.
